# 👥 Políticas de RH e Departamento Pessoal - Grupo 3SA

## 📋 Políticas Disponíveis

### 🏖️ Solicitação de Férias
- **Arquivo**: `policies/solicitacao-ferias.html`
- **Versão**: 1.0.0
- **Responsável**: Departamento de RH
- **Descrição**: Procedimentos para solicitação, aprovação e agendamento de férias

**Principais Tópicos:**
- Prazos para solicitação (30-60 dias de antecedência)
- Documentação necessária
- Processo de aprovação (Colaborador → Gestor → RH)
- Período aquisitivo e concessivo
- Observações legais importantes

### 📋 Checklist de Desligamento
- **Arquivo**: `policies/checklist-desligamento.html`
- **Versão**: 2.0.0
- **Responsável**: Departamento Pessoal
- **Descrição**: Procedimentos completos para processo de desligamento

**Principais Tópicos:**
- Tipos de desligamento (sem justa causa, justa causa, pedido, acordo mútuo)
- Prazos legais obrigatórios
- Documentos necessários (TRCT, ASO, guias)
- Checklist completo do DP
- Processo de homologação
